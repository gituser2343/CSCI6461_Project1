Overview
This repository contains Part I of the CSCI 6461 Computer Architecture CPU Simulator. This version includes a fully integrated memory cache and an interface to monitor real-time cache contents. All baseline functionality, such as program execution and loading .load files, works as expected.

Files in This Repository

CSCI6461Simulator.html: The CPU simulator web application.

Report.pdf: Documentation describing the cache implementation and test case walk-throughs.

test files/: Directory containing assembly (.asm) and simulator load (.load) files for testing.

How to Run

Open CSCI6461Simulator.html in a web browser.

Load a .load file from the test files folder using the file input.

Run the simulator to view register states and cache activity.
